# Smart Countdown Clock & Timer
## Python Experiential Learning Project — Phase III

This is the same Smart Countdown Clock & Timer project, keeping the original command-line Python program and the existing Flask browser interface. Phase III adds deployment configuration and cross-platform compatibility for hosting.

## Features
- Preset timers: 30 seconds, 1 minute, and 5 minutes
- Custom minutes and seconds with Python-side validation
- Browser countdown, progress display, pause, reset, clear, and completion alarm
- Original command-line timer retained in `countdown_timer.py`
- Flask API endpoint: `POST /api/time`
- GitHub-compatible source structure and Render deployment configuration

## Run locally in VS Code (Windows)

1. Install Python 3.10 or newer and VS Code.
2. Extract this ZIP file.
3. In VS Code, choose **File → Open Folder** and select the extracted `Python-Experiential-Learning-Deployable` folder.
4. Open **Terminal → New Terminal**.
5. Create a virtual environment:
   ```powershell
   py -m venv .venv
   ```
6. Activate it:
   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```
   If PowerShell blocks activation, use Command Prompt terminal and run:
   ```bat
   .venv\Scripts\activate.bat
   ```
7. Install dependencies:
   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```
8. Start the web app:
   ```powershell
   python app.py
   ```
9. Open `http://127.0.0.1:5000` in Chrome or Edge.
10. Keep the terminal running while you use the app. Press `Ctrl+C` in the terminal to stop it.

### Run the original command-line version
In the VS Code terminal, run:
```powershell
python countdown_timer.py
```
This preserves the original Python terminal experience. Windows keeps the system beep. On Linux hosts, the Windows-only system beep is skipped so imports and web deployment do not fail; the browser app uses its own alarm.

## Test the web app
- Click each preset and Start.
- Test Pause, Reset, and Clear.
- Set a custom duration such as 1 minute and 30 seconds.
- Test invalid values such as negative minutes, seconds `60`, or `0:00`.
- Allow a short timer to reach zero and check the completion message/alarm.

## Deploy the Flask app on Render
**Do not use GitHub Pages for this Flask app.** GitHub Pages only serves static files and cannot run `app.py` or the `/api/time` endpoint.

1. Push this folder's contents to the root of your GitHub repository.
2. Sign in at https://render.com and create **New → Web Service**.
3. Connect `Amitjapulkar26/Python-Experiential-Learning` (or the repository where you uploaded these files) and select branch `main`.
4. Set:
   - **Runtime:** Python
   - **Build command:** `pip install -r requirements.txt`
   - **Start command:** `gunicorn app:app`
5. Deploy and open the live URL Render provides.
6. Verify the home page and custom-time validation. Only use the live URL in the final PPT/report after it works.

The included `Procfile` also declares `web: gunicorn app:app`. Render can use the explicit start command above.
